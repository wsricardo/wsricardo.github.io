# Design de Site Pessoal 

Especificações para design em uma versão mais simplificada dos modelos já desenvolvidos e uma visão moderna e mais minimalista de fácil leitura pelo usuário e de fácil manutenção pelo autor do site.

## Identidade Visual

    - Cores claras: branco e cinzas claros. Preto para footer unicamente.
    - Fontes (tipografia) : sóbrias e tradicionais para textos e leituras confortável. 
    - Responsividade: Melhorias de responsividade para permitir o acesso confortável ao site a partir de dispositivos diversos ( smart tv, celular, tablets, smartwatchs)

## Layout
    - header : contém o titulo "WSRicardo" tamanho 18 px; e menu de navegação com iténs "Home", "Matemática", "Computação", "Artes", "Blog" 
    - body-content: corpo de conteúdo, centro vertical do layout contendo publicações e conteúdos do site
    - footer:  com links para blog antigo wsricardo.blogspot.com, e github.com/wsricardo

## Pelican

Pelican Python usado para atualizar os conteúdos da seções.  O gerenciamento será feito em wsricardo-admin onde conteúdo criado é salvo para cada seção e as páginas são geradas atualizando o conteúdo de cada seção contendo textos, imagens e links de vídeos ( enviados ou anexados via youtube ).

    - Seções:
        - Matemática
        - Computação
        - Artes
        - Blog ( contendo textos em gerais, crônicas, notícias, )
